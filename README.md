# HomePilot website

Portable static marketing website for `homepilot.ae`.

## Preview locally

From this directory, serve the files with any static HTTP server. For example:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Deploy

Upload the contents of this directory (not the directory itself) to the web root of any static host. No build step or
server runtime is required.

## Before public launch

- Replace indicative pricing if the commercial catalogue changes.
- Have the draft privacy statement legally reviewed.
- Add a telephone or WhatsApp contact only after the business number is confirmed.
- Confirm the web host and point `homepilot.ae` DNS to it.
- Verify that `sales@homepilot.ae` and `support@homepilot.ae` are receiving messages.
